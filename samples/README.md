# Samples

Store local test inputs here only. Customer MSG files, attachments, extracted values, and customer-derived expected results are excluded from source control.

The exception is [synthetic/](synthetic/README.md): 20 generated scenarios with invented companies, PROs and amounts (`scripts/synthetic_samples/generate.py`), tracked so anyone can run the pipeline, the [load test](../docs/load-testing.md) and the [golden-set evaluation](../docs/evaluation.md) without real data.
